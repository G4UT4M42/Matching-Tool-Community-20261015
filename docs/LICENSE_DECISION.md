# Proposed source license — MIT

The Community Edition working tree includes a provisional MIT license in `LICENSE`. This is a **proposal for the owner's own original code only** and is not a warranty that every included source file, third-party dependency, font, schema or asset may be redistributed under MIT.

The original application source may contain upstream copyrights and third-party snippets. Prior to public GitHub visibility, obtain owner confirmation of code ownership and licensing choice, enumerate third-party notices, check all upstream licenses, and obtain redistribution permission or remove/rewrite any unclear assets.

Specifically, Austrian SEPA XSD files were **excluded from this public candidate tree** while their redistribution rights remain unverified. Real SEPA creation, submission and unattended browser banking are disabled in the Community developer preview.

If any non-permissive license or unknown provenance is detected, block publication until the material is removed, replaced, or authorized and necessary NOTICE files are generated. Do not use CI passing as a legal rights signoff.

Once licensing is verified, update the public release checklist and include the final notices. A signed source ownership/redistribution gate is required before public visibility.
